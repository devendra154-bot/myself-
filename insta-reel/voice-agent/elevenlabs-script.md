# ElevenLabs Script — Voice Agent Reveal Reel

Paste-ready Telugu text for ElevenLabs text-to-speech. English brand names stay in English letters so they're pronounced correctly.

## Settings
- **Model:** pick a model that lists **Telugu** (Eleven v3 supports many Indian languages; check the model dropdown)
- **Voice:** a warm, energetic male or female voice (try a few in the Voice Library and filter by Telugu)
- **Feel:** friendly, confident, slightly fast. If you see sliders: Stability ~45%, Similarity ~75%, Style ~25%, Speed ~1.05
- **Output:** mp3, then send both files to me

## Tips
- A blank line between sentences gives a natural pause. "..." gives a slightly longer, dramatic pause
- If a word sounds wrong, respell it the way it sounds (e.g. "ఎలెవెన్ ల్యాబ్స్" instead of "ElevenLabs") and regenerate only that part
- Generate 2–3 takes and keep the most natural one
- If your plan's character limit is tight, Part A ≈ 250 characters and Part B ≈ 400 characters
